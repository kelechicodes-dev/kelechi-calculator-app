# Kelechi Calculator (Mobile)

A calculator app built with React Native and Expo.

## About

This is a mobile version of my original web-based calculator (see [typescript-work](https://github.com/kelechicodes-dev/typescript-work)), converted to run as a real cross-platform app using React Native.

## Features
- Addition, subtraction, multiplication, division
- Input validation (empty fields & divide-by-zero handling)
- Rounded results
- Clear button
- Styled UI with a card-based layout

## Technologies Used
- React Native
- Expo
- TypeScript

## Running the App
1. Install dependencies: `npm install`
2. Start the dev server: `npx expo start`
3. Scan the QR code with the Expo Go app on your phone
